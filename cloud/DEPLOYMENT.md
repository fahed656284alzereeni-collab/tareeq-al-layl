# النشر والإصدارات

## إعدادات البناء
- Platform: Cloudflare Pages
- Root directory: `cloud`
- Build command: `npm run build`
- Output: `dist`
- Runtime secrets: لا توجد أسرار خادم مطلوبة في واجهة المتصفح. المفتاح المستخدم هنا Publishable key فقط.

## الفروع
- `main`: النسخة القديمة الحالية، لا تلمسها عملية الترحيل.
- `mersal-cloudflare-migration`: فرع إعادة البناء والمعاينة.
- بعد نجاح الاختبارات فقط، ترفع تغييرات محددة عبر Pull Request.
